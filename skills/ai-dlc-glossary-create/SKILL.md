# AI-DLC 도메인 표준 용어 생성

요구사항 문서·기능 명세·비즈니스 규칙 등에서 **도메인 핵심 용어**를 추출하고, 동의어를 통합해 **표준 용어사전**을 생성한다. 팀 전체가 동일한 언어로 소통하도록 돕는다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "도메인 표준 용어 생성", "용어사전 만들어줘", "도메인 용어 정의", "글로서리 작성"
- "용어 정의해줘", "용어 통일해줘", "표준 용어 만들어줘", "도메인 용어집 작성"
- 요구사항 문서를 보여주며 "이 문서의 주요 용어 정리해줘"라고 할 때

## 용어 추출 전략

1. **명사형 도메인 키워드 추출**: 비즈니스 행위자, 데이터 엔터티, 프로세스 명사
   - 추출 대상 예: "회원", "주문", "결제수단", "배송지", "쿠폰", "재고"
   - 제외 대상: 일반 동사, 기술 용어(React, JWT 등 고유명사 → 원문 유지)
2. **동의어 통합**: 같은 개념의 다른 표현을 묶어 대표 용어 결정
   - 예: "회원" = "사용자" = "고객" → 대표 용어: "회원" (시스템 내부 호칭 기준)
3. **정의 생성**: 해당 시스템 맥락에서의 정의 (일반 사전 정의 아님)
4. **도메인 분류**: 어느 서비스/기능 영역의 용어인지 분류

## 진행 절차

1. **추출**: 위 전략으로 용어 목록 생성
2. **통합**: 동의어 후보 묶음 → 대표 용어 결정
3. **정의**: 각 용어의 시스템 내 정의 작성
4. **초안 생성**: `${CLAUDE_SKILL_DIR}/template.md` 기반 용어사전 작성
5. **대표 용어 불명확 확인**: 동의어 후보 중 대표 용어 결정이 어려운 경우 묶어 1회 질문

## 산출물 포맷

파일명: `용어사전_{사업명}_{YYYYMMDD}.md`

### 도메인 표준 용어 테이블
```
| TM-ID | 용어 | 정의 | 도메인 | 동의어/유사어 | 사용 예시 | 출처 | 상태 |
```
- TM-NNN 형식 자동 채번 (001부터)
- 출처: `내부정의` / `ISO NNN` / `국가표준 KS-XXXXX` / `업계 관행` 등
- 상태: 초안 (신규 생성 시 전부 "초안")

## 작성 원칙

- 정의는 최소 1개의 완전한 문장 (단어 나열 불가)
- 정의에서 다른 용어를 참조할 때는 같은 용어사전에 있는 용어를 사용 (순환 정의 지양)
- 동의어/유사어 컬럼: 이 용어사전에서 **사용하지 않기로 결정한** 표현 목록
- 기술 고유명사는 용어사전 대상이 아님 (React, JWT 등)

## 엣지 케이스

- **용어가 너무 많은 경우 (100개 이상)**: 핵심 도메인 용어 50개 우선 정의, 나머지는 "확장 용어" 섹션 별도 처리
- **도메인 분류가 명확하지 않은 경우**: `공통` 도메인으로 분류
- **사전에 정의가 어려운 추상 용어**: 사용 예시만 제공하고 정의는 TODO 처리
- **영어 원문 용어**: 한국어 번역과 영어 원문 모두 기재 (예: "배포 → 배포(Deployment)")

## 예시

**입력:** "회원이 장바구니에 상품을 담고, 쿠폰을 적용해 주문 생성 후 결제한다."

**출력 발췌:**
```markdown
| TM-ID | 용어 | 정의 | 도메인 | 동의어/유사어 | 사용 예시 | 출처 | 상태 |
|:---|:---|:---|:---|:---|:---|:---|:---:|
| TM-001 | 회원 | 서비스에 가입 완료하고 로그인 상태로 서비스를 이용하는 개인 | 사용자관리 | 사용자, 고객, 유저 | "회원이 로그인한다", "회원 정보 수정" | 내부정의 | 초안 |
| TM-002 | 장바구니 | 회원이 구매를 결정하기 전 관심 상품을 임시로 보관하는 공간 | 주문 | 장바구니, 카트 | "장바구니에 담기", "장바구니 조회" | 내부정의 | 초안 |
| TM-003 | 쿠폰 | 특정 조건에서 주문 금액을 할인받을 수 있는 디지털 할인권 | 마케팅 | 할인쿠폰, 프로모션코드 | "쿠폰 적용하기", "쿠폰 코드 입력" | 내부정의 | 초안 |
```
