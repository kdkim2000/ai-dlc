# AI-DLC 소스코드 영향도 분석

변경 대상(파일, 함수, 클래스, 모듈)을 입력받아 코드베이스 전체에서 직접·간접 참조를 추적하고 **영향 범위와 위험도**를 산출한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "영향도 분석", "영향 범위 파악", "변경 영향 분석", "어디까지 영향 가?"
- "impact analysis", "변경하면 뭐가 바뀌어?", "영향 받는 파일 찾아줘"
- 특정 파일/함수 이름을 언급하며 "이거 수정하면 어디 영향 가?"라고 할 때

## 입력

- **필수**: 변경 대상 (파일 경로 또는 함수명/클래스명)
- **선택**: 분석 범위 경로 (기본: 현재 작업 디렉터리), 제외 경로 (node_modules, .git 등)

## 분석 절차

1. **대상 파악**: 입력이 파일 경로이면 해당 파일의 export/public 심볼 목록 추출. 함수명이면 해당 심볼만 대상
2. **1차 영향 탐색**: `Grep`으로 대상 심볼명을 전체 코드베이스에서 참조하는 파일 탐색
3. **2차 영향 추적**: 1차 영향 파일들이 export하는 심볼을 다시 참조하는 파일 탐색 (1단계만)
4. **영향 분류**:
   - **직접(1차)**: 변경 대상을 직접 import·호출하는 파일
   - **간접(2차)**: 1차 파일을 통해 간접 영향 받는 파일
   - **안전**: 참조 없음 (독립적)
5. **중요도 산정**: 테스트 파일, 진입점(main/index/app), API 라우터는 중요도 `높음` 자동 부여
6. **보안 경고**: 분석 중 하드코딩된 시크릿 패턴 발견 시 별도 경고 섹션에 표시

## 산출물 포맷

파일명: `영향도분석_{대상명}_{YYYYMMDD}.md`

### 필수 섹션

```markdown
# 소스코드 영향도 분석서

| 항목 | 내용 |
|:---|:---|
| 분석 대상 | {파일/함수명} |
| 변경 내용 | {예정 변경 내용} |
| 분석 범위 | {경로} |
| 분석 일시 | {YYYY-MM-DD} |

## 1. 변경 대상 요약
## 2. 직접 영향 항목 (1차)
| 파일 경로 | 참조 위치 | 영향 유형 | 중요도 |
## 3. 간접 영향 항목 (2차)
| 파일 경로 | 경유 파일 | 중요도 |
## 4. 안전 영역 (영향 없음)
## 5. 테스트 필요 항목
| 파일 경로 | 테스트 유형 | 우선순위 |
## 6. 위험 평가
| 위험 수준 | 근거 | 권고 조치 |
```

- 영향 유형: `직접 호출` / `타입 참조` / `상속/구현` / `설정 참조`
- 중요도: `높음` / `중간` / `낮음`
- 위험 수준: `높음(즉시 확인)` / `중간(검토 권장)` / `낮음(모니터링)`

## 언어별 참조 탐색 패턴

| 언어 | import 패턴 | Grep 키워드 |
|:---|:---|:---|
| TypeScript/JS | `import.*from`, `require(` | 파일명, 함수명 |
| Python | `from.*import`, `import ` | 모듈명, 함수명 |
| Java | `import `, 클래스명 직접 사용 | 클래스명, 메서드명 |
| Go | `import`, 패키지명.함수명 | 패키지명, 함수명 |

## 작성 원칙

- `node_modules`, `.git`, `dist`, `build`, `__pycache__` 디렉터리는 분석 제외
- 테스트 파일(`*.test.*`, `*.spec.*`, `*_test.go`, `test_*.py`)은 별도 구분하여 표시
- 영향 항목이 50개 초과 시 상위 20개만 상세 표시, 나머지는 건수만 요약

## 엣지 케이스

- **흔한 이름(e.g. `util`, `helper`)**: 오탐 가능성 경고 후 문맥 기반 필터링
- **동적 import (변수 경로)**: 정적 분석 한계 명시, 수동 확인 필요 항목으로 분류
- **분석 범위가 너무 넓은 경우 (파일 100개+)**: 핵심 경로 우선 분석 + 전체 범위는 별도 섹션으로 요약
