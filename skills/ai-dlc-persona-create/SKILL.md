# AI-DLC 사용자 페르소나 정의

> 아이디어정의서 또는 자연어 설명에서 사용자 그룹을 도출하여 PS-NNN 페르소나 카드를 생성한다.
> 각 페르소나는 이름·역할·목표·불편함·행동 패턴·기술 수준을 포함하며,
> `ai-dlc-usecase-create`의 액터 정의 기반이 된다.

## 트리거

- "페르소나 만들어줘", "페르소나 분석해줘"
- "사용자 정의해줘", "사용자 유형 정의해줘"
- "누가 사용하는지 정리해줘", "타겟 사용자 분석해줘"
- "사용자 그룹 정의해줘", "액터 정의해줘"

## 입력

### 필수 (택일)
- `아이디어정의서_*.md` 파일 (자동 탐색)
- 자연어 설명 (사용자/서비스 개요)

### 선택
- 기존 사용자 조사 자료, 인터뷰 내용

## 처리 절차

1. **아이디어정의서 탐색**
   - `Glob("아이디어정의서_*.md")` → `Read`
   - 없으면 입력 자연어에서 직접 추출

2. **사용자 그룹 도출**
   - 아이디어정의서의 "사용자 그룹" 섹션 추출
   - 없으면 서비스 도메인 기반 추론:
     - 일반 사용자 / 관리자 / 운영자 / 시스템 구분
     - 그룹당 1개 페르소나 생성

3. **PS-NNN 채번** (001부터 순차)

4. **페르소나 카드 작성** (그룹별)
   - 대표 이름(가상) + 직군 + 나이대
   - 주요 목표 (2~3가지)
   - 불편한 점(Pain) (2~3가지)
   - 원하는 것(Gain) (2~3가지)
   - 기술 친숙도: 낮음/보통/높음
   - 주요 사용 시나리오 (1~2가지)

5. **`template.md` 기반 파일 생성**

## 산출물

파일명: `페르소나_{사업명}_{YYYYMMDD}.md`
- 출력 시 절대 경로 + PS 건수 표시

## 엣지 케이스

- **사용자 그룹 불명확**: "일반 사용자"와 "관리자" 2개 기본 페르소나 생성 후 확인 요청
- **B2B 서비스**: 기업 의사결정자 / 실무 담당자 / 최종 사용자 3계층으로 분류
- **PS가 1개뿐인 경우**: 단일 그룹이라도 페르소나 카드 형식으로 작성
