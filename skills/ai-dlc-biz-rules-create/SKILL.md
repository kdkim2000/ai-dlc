# AI-DLC 비즈니스 규칙 생성

요구사항 문서에서 **비즈니스 규칙(Business Rules)**을 자동 도출하고 BR 테이블로 정리한다. 비즈니스 규칙은 "조건(If/When) → 행동(Then)" 구조로, 시스템이 따라야 할 업무 규칙을 명확히 정의한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "비즈니스 규칙 생성", "비즈니스 규칙 도출", "BR 작성", "업무 규칙 정의"
- "비즈니스 룰 만들어줘", "비즈니스 규칙 뽑아줘", "규칙 목록 만들어줘"
- 요구사항 문서를 보여주며 "이 안에서 규칙 뽑아줘"라고 할 때

## 비즈니스 규칙 추출 전략

다음 패턴을 요구사항 문서에서 탐색해 BR로 변환한다:

| 패턴 | 예시 | BR 변환 |
|:---|:---|:---|
| `~해야 한다` | "비밀번호는 8자 이상이어야 한다" | 조건: 비밀번호 입력 시 / 행동: 8자 이상 검증 |
| `~인 경우 ~한다` | "재고가 0인 경우 주문 불가" | 조건: 재고 수량 = 0 / 행동: 주문 버튼 비활성화 |
| `~이면 ~처리한다` | "5회 실패 시 계정 잠금" | 조건: 로그인 실패 5회 / 행동: 계정 잠금 처리 |
| `~하지 않는다` / `~금지` | "관리자 계정은 삭제 금지" | 조건: 관리자 계정 삭제 요청 시 / 행동: 삭제 차단 |
| `~단계 / ~프로세스` | "주문 → 결제 → 배송 순서" | 조건: 결제 미완료 / 행동: 배송 처리 불가 |
| 예외·오류 처리 | "결제 실패 시 3회 재시도" | 조건: 결제 실패 / 행동: 최대 3회 재시도 |

## 진행 절차

1. **입력 파싱**: 요구사항 문서 전체에서 위 패턴 탐색
2. **클러스터링**: 유사 규칙을 도메인별로 묶기 (회원/주문/결제/보안 등)
3. **초안 생성**: `${CLAUDE_SKILL_DIR}/template.md` 기반 BR 테이블 작성
4. **중복 제거**: 실질적으로 동일한 규칙은 통합
5. **누락 확인**: 주요 예외 케이스 누락 시 묶어 1회 질문

## 산출물 포맷

파일명: `비즈니스규칙_{사업명}_{YYYYMMDD}.md`

### 비즈니스 규칙 테이블
```
| BR-ID | 규칙명 | 도메인 | 조건 (When/If) | 행동 (Then) | 우선순위 | 상태 |
```
- BR-NNN 형식 자동 채번, 도메인별 그룹 후 각 그룹 내 순차 채번
- 우선순위: 높음 / 중간 / 낮음
- 상태: 초안 (신규 생성 시 전부 "초안")
- 연관 FR 표시: 가능하면 비고에 `(FR-NNN 참조)` 추가

## 작성 원칙

- 조건은 구체적인 트리거로 작성: "~할 때", "~이면", "~인 경우"
- 행동은 명확한 동작으로 작성: "~한다", "~처리한다", "~반환한다"
- 한 규칙에 조건이 여러 개면 AND/OR 관계를 명시
- 규칙명은 `{도메인}_{행동}` 형식 권장 (예: 로그인_계정잠금, 주문_재고검증)

## 엣지 케이스

- **요구사항이 아닌 단순 기능 설명만 있는 경우**: "~기능" → 암묵적 규칙 추론 (예: "장바구니 담기" → "비로그인 시 로그인 페이지 이동" 규칙 생성)
- **규칙이 너무 많은 경우 (30개 이상)**: 도메인별 별도 섹션으로 분리 + 요약 표 추가
- **조건/행동이 불명확한 경우**: `<!-- TODO: 조건/행동 상세화 필요 -->` 표시

## 예시

**입력:** "로그인 5회 실패 시 계정 잠금. 비밀번호는 8자 이상, 대소문자+특수문자 포함. 미성년자 주류 구매 불가."

**출력 발췌:**
```markdown
| BR-ID | 규칙명 | 도메인 | 조건 (When/If) | 행동 (Then) | 우선순위 | 상태 |
|:---|:---|:---:|:---|:---|:---:|:---:|
| BR-001 | 로그인_계정잠금 | 인증/보안 | 로그인 실패 횟수가 5회에 달하면 | 해당 계정을 잠금 처리하고 "계정이 잠겼습니다" 메시지 표시 | 높음 | 초안 |
| BR-002 | 비밀번호_복잡도 | 인증/보안 | 비밀번호 설정 또는 변경 시 | 8자 이상, 대문자 1개 이상, 소문자 1개 이상, 특수문자 1개 이상인지 검증. 미충족 시 설정 거부 | 높음 | 초안 |
| BR-003 | 주문_연령제한 | 주문 | 주류 상품 주문 시 | 회원 연령이 19세 미만이면 구매 차단 및 안내 메시지 표시 | 높음 | 초안 |
```
