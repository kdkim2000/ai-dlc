# AI-DLC 납품 검수 목록

> 프로젝트 디렉터리의 AI-DLC 산출물을 자동 탐색하여 단계별 필수·권장 항목 충족 여부를 검사하고
> 납품 가능 여부를 판정한 `납품검수목록_*.md`를 생성한다.

## 트리거

- "납품 검수 목록 만들어줘", "납품 산출물 확인해줘"
- "인도 문서 체크해줘", "납품 준비 상태 확인해줘"
- "deliverable 목록 만들어줘", "산출물 완성도 확인"
- "납품 전 검수해줘", "어떤 문서가 빠졌는지 확인해줘"

## 입력

### 필수
- 현재 작업 디렉터리 (자동 탐색)

### 선택
- 사업명 (없으면 디렉터리명 또는 요구사항정의서에서 추출)

## 처리 절차

1. **산출물 탐색 (Glob 패턴)**

   필수 항목 (없으면 ❌):
   - `요구사항정의서_*.md`
   - `유즈케이스_*.md`
   - `화면정의서_*.md` 또는 `화면목록_*.md`
   - `openapi_*.yaml` 또는 `API설계서_*.yaml` 또는 `API설계서_*.md`
   - `데이터설계서_*.md`
   - `코드품질검토_*.md`
   - `e2e테스트_검증_*.md`

   권장 항목 (없으면 ⚠️):
   - `서비스분류_*.md`
   - `비즈니스규칙_*.md`
   - `용어사전_*.md`
   - `클래스설계서_*.md`
   - `docs/change-log.md`
   - `프로그램분석서_*.md`

   선택 항목 (참고용, ℹ️):
   - `아이디어정의서_*.md`
   - `사용자스토리맵_*.md`
   - `MVP범위정의서_*.md`
   - `페르소나_*.md`

2. **파일 정보 수집**
   - 각 파일에서 버전 이력 표의 최신 버전 번호 추출 (Grep으로 `v\d+\.\d+` 패턴)
   - 파일이 여러 개면 최신 수정일 기준으로 선택

3. **종합 판정**
   - 필수 항목 전체 ✅ → "납품 가능"
   - 필수 항목 1개 이상 ❌ → "보완 필요"
   - 권장 항목 누락 → "조건부 납품 가능 (권장 보완)"

4. **template.md 기반 파일 생성**

## 산출물

파일명: `납품검수목록_{사업명}_{YYYYMMDD}.md`
- 출력 시 절대 경로 + 필수/권장/선택 건수 + 종합 판정 결과

## 다음 단계 안내

검수 완료 후 납품 문서 생성 권장:
```
→ "시스템 개요서 만들어줘"   (ai-dlc-system-overview)
→ "사용자 매뉴얼 만들어줘"   (ai-dlc-user-manual)
→ "개발자 가이드 만들어줘"   (ai-dlc-dev-guide)
        ↓
→ "납품 패키지 만들어줘"     (ai-dlc-delivery-package)
```

## 엣지 케이스

- **산출물이 하나도 없는 경우**: 전 항목 ❌로 표시하고 AI-DLC 단계별 시작 스킬 안내
- **동일 유형 파일 여러 개**: 최신 수정일 기준 1개를 대표 파일로 선택, 나머지는 "이전 버전" 표시
- **서브 디렉터리에 있는 경우**: `**/*.md` 패턴으로 재귀 탐색
