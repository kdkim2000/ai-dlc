# AI-DLC 납품 패키지 최종화

> 프로젝트 디렉터리의 모든 AI-DLC 산출물을 카테고리별로 수집하고
> 버전·생성일·연계 관계를 정리한 `납품패키지_인덱스_*.md`를 생성한다.
> 이 문서는 납품 시 제출하는 최상위 목차이며, Word 변환 안내를 포함한다.

## 트리거

- "납품 패키지 만들어줘", "최종 납품 정리해줘"
- "산출물 최종 정리해줘", "인도 패키지 생성해줘"
- "납품 인덱스 만들어줘", "최종 납품 문서 묶어줘"
- "납품 목록 최종화해줘", "인수인계 패키지 만들어줘"

## 입력

### 필수
- 현재 작업 디렉터리 (자동 탐색)

### 선택
- `납품검수목록_*.md` (ai-dlc-delivery-checklist 결과, 있으면 종합 판정 포함)

## 처리 절차

1. **전체 산출물 Glob 탐색**
   - `*.md`, `*.yaml`, `*.yml`, `*.docx` 모두 탐색
   - 카테고리 자동 분류 (파일명 패턴 기반):
     ```
     아이디어 단계:    아이디어정의서_*, 페르소나_*, 사용자스토리맵_*, MVP범위정의서_*
     요구사항 정의:    요구사항정의서_*, 서비스분류_*, 기능요구사항_*, 비기능요구사항_*
     분석:            비즈니스규칙_*, 용어사전_*
     설계:            유즈케이스_*, 화면목록_*, 화면정의서_*, openapi_*, API설계서_*,
                      데이터설계서_*, 클래스설계서_*, 시퀀스다이어그램_*
     개발·검증:        코드품질검토_*, e2e테스트_검증_*, 프로그램분석서_*
     변경 관리:        docs/change-log.md, 영향도분석_*
     납품 전용:        시스템개요서_*, 사용자매뉴얼_*, 개발자가이드_*, 납품검수목록_*
     ```

2. **파일별 정보 수집**
   - 각 파일에서 버전 이력 표의 최신 버전 번호 추출
   - 파일 수정일 기록

3. **문서 간 연계 관계도 생성** (ASCII)
   ```
   요구사항정의서 ─→ 서비스분류 ─→ 유즈케이스 ─→ 화면정의서 ─→ 사용자매뉴얼
                                                 ─→ API설계서  ─→ 개발자가이드
                                                 ─→ 데이터설계서
   ```

4. **Word 변환 안내 생성**
   - 변환 대상 파일 목록 (설계서·매뉴얼 등 주요 문서)
   - `ai-dlc-md-to-word 변환해줘` 트리거 안내

5. **납품 검수 결과 요약** (납품검수목록이 있으면)

6. **template.md 기반 파일 생성**

## 산출물

파일명: `납품패키지_인덱스_{사업명}_{YYYYMMDD}.md`
- 출력 시 절대 경로 + 총 산출물 수 + 카테고리별 건수

## 엣지 케이스

- **납품 전용 문서(시스템개요서·사용자매뉴얼·개발자가이드) 없는 경우**: 생성 권장 안내 추가
- **하위 디렉터리에 산출물 있는 경우**: 재귀 탐색하여 상대 경로로 기록
- **Word 파일(.docx)이 이미 있는 경우**: 변환 목록에서 제외하고 "Word 파일 존재" 표시
