# AI-DLC 코드 복잡도·품질 분석

소스파일 전체를 정적 분석하여 함수별 복잡도를 측정하고 리팩토링 우선순위와 기술 부채를 도출하여 **복잡도·품질 분석서**를 산출한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

> **한계 명시**: 이 분석은 Claude의 정적 텍스트 분석 기반으로 전용 도구(SonarQube, pylint, ESLint, radon) 대비 **근사치**임을 결과에 명기한다.

- "코드 복잡도", "복잡한 코드 찾아줘", "품질 분석", "리팩토링 후보"
- "기술 부채 분석", "code complexity", "사이클로매틱 복잡도"
- "유지보수 어려운 코드", "함수 너무 길어", "코드 품질 평가"
- 특정 파일/디렉터리를 주며 "복잡도 분석해줘"라고 할 때

## 입력

- **필수**: 분석 대상 경로 (디렉터리 또는 특정 파일)
- **선택**: 언어 지정 (기본: 자동 감지)

## 분석 절차

1. **소스파일 수집**: `Glob`으로 소스파일 목록 수집 (`node_modules`, `dist`, `__pycache__` 제외)
2. **언어 감지**: 파일 확장자로 자동 판별
3. **파일별 측정**:
   - **LOC**: 총 줄 수 (빈 줄·주석 제외한 실질 코드 줄 수)
   - **함수/메서드 수**: 언어별 선언 패턴 `Grep`으로 계산
   - **최대 중첩 깊이**: 들여쓰기 레벨로 추정
4. **함수별 복잡도 추정**:
   - 사이클로매틱 복잡도(CC) ≈ 분기문(`if`, `else if`, `elif`, `for`, `while`, `case`, `catch`, `&&`, `||`) 수 + 1
   - 등급 산정: A(1~5) / B(6~10) / C(11~15) / D(16~20) / F(21+)
5. **상위 고복잡도 함수 추출**: 등급 C 이상 함수 전체 + 등급 B 상위 10개
6. **TODO/FIXME/HACK 주석 탐지**: `Grep`으로 위치 및 내용 추출
7. **개선 권고**: 함수 분리, 조건 단순화, 패턴 적용 제안

## 산출물 포맷

파일명: `복잡도분석_{시스템명}_{YYYYMMDD}.md`

`${CLAUDE_SKILL_DIR}/template.md` 골격 사용:

1. **파일별 복잡도 요약** (LOC·함수 수·등급)
2. **고복잡도 함수 목록** (등급 C 이상, 리팩토링 후보)
3. **품질 지표 요약** (전체 LOC, 평균 복잡도, 기술 부채 추정)
4. **TODO/FIXME 현황**
5. **개선 권고** (우선순위 포함)

## 복잡도 등급 기준

| 등급 | 사이클로매틱 복잡도 | 의미 | 조치 |
|:---:|:---:|:---|:---|
| A | 1 ~ 5 | 단순, 이해하기 쉬움 | 유지 |
| B | 6 ~ 10 | 보통, 관리 가능 | 모니터링 |
| C | 11 ~ 15 | 복잡, 테스트 어려움 | 리팩토링 검토 |
| D | 16 ~ 20 | 매우 복잡, 오류 위험 | 즉시 리팩토링 |
| F | 21+ | 극도로 복잡 | 재설계 필요 |

## 언어별 복잡도 측정 패턴

| 언어 | 분기 카운트 대상 |
|:---|:---|
| TypeScript/JS | `if`, `else if`, `for`, `while`, `switch case`, `catch`, `&&`, `\|\|`, `?.` |
| Python | `if`, `elif`, `for`, `while`, `except`, `and`, `or` |
| Java/Kotlin | `if`, `else if`, `for`, `while`, `case`, `catch`, `&&`, `\|\|` |
| Go | `if`, `for`, `case`, `&&`, `\|\|` |

## 작성 원칙

- `node_modules`, `.git`, `dist`, `build`, `__pycache__` 제외
- 테스트 파일은 별도 섹션에서 분리 집계
- 파일 수 50개 초과 시 등급 C 이상 파일만 상세, 나머지는 집계 요약
- 분석 정확도 한계를 서두에 명기

## 엣지 케이스

- **단일 함수가 수백 줄**: 그 자체로 F등급 + 별도 강조 표시
- **생성 코드(proto, swagger)**: 복잡도 분석 제외 후 "(생성 코드)" 표시
- **주석 비율이 매우 낮음**: 문서화 부족으로 기술 부채 경고 추가
