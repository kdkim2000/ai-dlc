# AI-DLC 데이터 설계 수정

검증 보고서 또는 자연어 지시에 따라 데이터 설계서(ERD·테이블 정의서·DDL 초안)를 수정하고 버전을 +0.1 증가시켜 새 파일로 저장한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "데이터 설계 수정", "ERD 수정", "테이블 수정해줘", "데이터 검증 반영"
- "컬럼 추가해줘", "테이블 버전 올려줘", "DB 설계 업데이트"
- 검증 보고서를 주며 "반영해줘"라고 할 때
- 데이터 설계서를 주며 "이 테이블 고쳐줘"라고 할 때

## 입력

- **필수**: 기존 데이터 설계서 (`ai-dlc-data-design` 산출물)
- **선택**: 검증 보고서 (`ai-dlc-data-validate` 산출물), 자연어 수정 지시

## 처리 절차

1. **입력 방식 판별**:
   - 검증 보고서 있음 → VI-NNN 이슈 목록에서 변경 사항 자동 추출
   - 검증 보고서 없음 → 자연어 지시에서 변경 사항 파싱
2. **변경 목록 정리**: 테이블 추가/삭제, 컬럼 추가/수정/삭제, 관계 변경
3. **불명확 지시 확인**: 1회만, 3개 이하로 묶어서 질문
4. **변경 적용 (ERD·테이블 정의서·DDL 동시)**:
   - 테이블 추가: 공통 컬럼 자동 포함, Mermaid erDiagram 갱신
   - 테이블 삭제: 연관 FK 관계 정리, ERD 노드 제거
   - 컬럼 추가/수정: 테이블 정의서 + DDL + ERD 속성 동시 갱신
   - 관계 변경: ERD 관계 표기 + FK 제약 조건 동시 갱신
   - 정규화 적용: 위반 테이블 분해, 연관 테이블 FK 추가
5. **버전 증가**: 기존 버전 +0.1, 문서 버전 이력 표에 변경 내용 기록
6. **새 파일명으로 저장**: `데이터설계서_{사업명}_{YYYYMMDD}_v{N.N}.md`

## 변경 유형

| 변경 유형 | 처리 방법 |
|:---|:---|
| 테이블 추가 | ERD 노드 추가, 공통 컬럼 자동 포함, DDL CREATE TABLE 추가 |
| 테이블 삭제 | ERD 노드·관계 제거, 연관 FK 정리, DDL DROP TABLE 명시 |
| 컬럼 추가 | 테이블 정의서 행 추가, DDL ALTER TABLE ADD COLUMN 추가 |
| 컬럼 수정 | 타입·제약 변경, DDL ALTER TABLE MODIFY COLUMN 추가 |
| 관계 추가/변경 | ERD 관계 표기 수정, FK 제약 조건 DDL 갱신 |
| 정규화 수정 | 테이블 분해 시 기존 테이블 수정 + 신규 테이블 추가 동시 처리 |

## 특이사항

- ERD(논리/물리), 테이블 정의서, DDL 초안은 **반드시 동시 수정**: 세 섹션 간 불일치 금지
- 컬럼 삭제 시 해당 컬럼을 참조하는 FK 있으면 경고 메시지 출력
- API 설계서에서 참조 중인 컬럼 변경 시 연계 문서 갱신 안내 출력
