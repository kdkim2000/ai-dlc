# AI-DLC 유즈케이스 수정

검증 보고서 또는 자연어 지시에 따라 유즈케이스 문서를 수정하고 버전을 +0.1 증가시켜 새 파일로 저장한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "유즈케이스 수정", "UC 업데이트", "유즈케이스 검증 반영", "UC 수정해줘"
- "시나리오 변경", "유즈케이스 버전 올려줘", "UC 내용 바꿔줘", "유즈케이스 추가해줘"
- 검증 보고서를 주며 "반영해줘"라고 할 때
- 유즈케이스 문서를 주며 "이 부분 고쳐줘"라고 할 때

## 입력

- **필수**: 기존 유즈케이스 문서 (`ai-dlc-usecase-create` 산출물)
- **선택**: 검증 보고서 (`ai-dlc-usecase-validate` 산출물), 자연어 수정 지시

## 처리 절차

1. **입력 방식 판별**:
   - 검증 보고서 있음 → VI-NNN 이슈 목록에서 변경 사항 자동 추출
   - 검증 보고서 없음 → 자연어 지시에서 변경 사항 파싱
2. **변경 목록 정리**: UC 추가/삭제/수정, FR 연계 변경, 흐름 수정
3. **불명확 지시 확인**: 1회만, 3개 이하로 묶어서 질문 (모호한 지시가 있는 경우)
4. **변경 적용**:
   - UC 수정 시 연계 FR·인접 UC 영향 확인
   - UC 추가 시 UC-NNN 최대 번호 +1로 채번
   - UC 삭제 시 참조 UC·화면 목록 영향 경고
5. **버전 증가**: 기존 버전 +0.1, 문서 버전 이력 표에 변경 내용 기록
6. **새 파일명으로 저장**: `유즈케이스_{사업명}_{YYYYMMDD}_v{N.N}.md`

## 변경 유형

| 변경 유형 | 처리 방법 |
|:---|:---|
| UC 추가 | 최대 UC-NNN +1 채번, FR 연계 명시 필수 |
| UC 삭제 | 삭제 이유 변경 이력에 기록, 참조 UC 영향 경고 |
| 기본 흐름 수정 | 수정 전후 비교 가능하도록 변경 이력에 요약 |
| 예외 흐름 추가 | 해당 UC 예외 흐름 섹션에 추가 |
| FR 연계 변경 | FR-UC 커버리지 표 동시 갱신 |
| 액터 변경 | 액터 목록 및 해당 UC 모두 동시 수정 |

## 산출물 포맷

파일명: `유즈케이스_{사업명}_{YYYYMMDD}_v{N.N}.md`

전체 문서 구조는 `ai-dlc-usecase-create` template.md와 동일하게 유지.
문서 버전 이력 표에 변경 내용 행 추가:

```markdown
| v{N.N} | {일자} | 수정 반영 | {변경 내용 요약} |
```
