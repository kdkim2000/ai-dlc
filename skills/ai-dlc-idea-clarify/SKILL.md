# AI-DLC 아이디어 구체화

> 막연한 불편함·아이디어를 5W1H 인터뷰로 구체화하여 `아이디어정의서_*.md`를 생성한다.
> 이 산출물은 `ai-dlc-persona-create`, `ai-dlc-user-story-map`, `ai-dlc-mvp-scope`의 기반 입력이 된다.

## 트리거

- "아이디어 있는데", "앱 만들고 싶어", "서비스 기획하고 싶어"
- "이런 게 불편해", "이런 게 필요해", "뭔가 만들고 싶어"
- "시스템 만들려고", "뭘 만들면 좋을지 모르겠어"
- "아이디어 구체화해줘", "어떤 시스템이 필요한지 정리해줘"
- 자연어로 도메인·불편함·필요를 설명하는 경우

## 입력

### 필수
- 자연어 설명 (키워드 수준도 가능 — "근태관리", "쇼핑몰 관리 불편")

### 선택
- 참고 서비스명, 경쟁사, 벤치마크 URL
- 대략적인 사용자 수, 예산, 일정

## 처리 절차

1. **초안 추출**: 입력에서 5W1H 항목 파악
   - Who: 주요 사용자 / 운영자 그룹
   - What: 핵심 불편함 또는 원하는 기능
   - Why: 비즈니스 목표, 기대 효과
   - When/Scale: 사용 빈도, 예상 사용자 규모
   - Benchmark: 유사 서비스나 참고 사례

2. **부족 항목 판단 → 그룹 인터뷰**
   - 비어 있는 5W1H 항목이 있으면 **한 번에 묶어 질문** (최대 5문항)
   - 예:
     ```
     아이디어를 구체화하기 위해 몇 가지 여쭤볼게요:
     1. 이 서비스를 주로 누가 사용하게 되나요? (예: 직원, 고객, 관리자)
     2. 현재 어떤 방법으로 이 업무를 처리하고 있나요? (불편함 구체화)
     3. 이 서비스로 어떤 효과를 기대하나요? (목표)
     4. 예상 사용자 규모와 사용 빈도는 어느 정도인가요?
     5. 참고하고 싶은 유사 서비스나 앱이 있나요?
     ```
   - 답변이 있으면 바로 문서 생성 (재질문 없음)
   - 입력이 충분하면 바로 생성

3. **아이디어정의서 생성**: `template.md` 읽어 자리표시자 치환 후 파일 저장

## 산출물

파일명: `아이디어정의서_{사업명}_{YYYYMMDD}.md`
- 사업명: 입력에서 추출, 없으면 도메인 기반 추론 ("근태관리시스템")
- OS 금지 문자(`/ \ : * ? " < > |`)는 `_`로 치환
- 출력 시 절대 경로 + 생성된 섹션 요약 함께 표시

## 다음 단계 안내

생성 후 아래 스킬을 순서대로 실행 권장:
```
(병렬 가능)
→ "페르소나 만들어줘"       (ai-dlc-persona-create)
→ "사용자 스토리 만들어줘"  (ai-dlc-user-story-map)
        ↓
→ "MVP 정의해줘"            (ai-dlc-mvp-scope)
        ↓
→ "요구사항으로 변환해줘"   (ai-dlc-idea-to-req)
```

## 엣지 케이스

- **입력이 한 단어뿐**: 인터뷰 모드로 전환하여 5문항 모두 질문
- **이미 요구사항이 명확한 경우**: "요구사항 정의서 작성해줘"로 `ai-dlc-requirements` 사용 권장
- **여러 아이디어 혼재**: 핵심 아이디어 하나를 선택하도록 유도한 후 진행
