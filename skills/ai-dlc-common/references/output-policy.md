# AI-DLC 분석단계 공통 출력 정책

모든 AI-DLC 분석단계 스킬이 따르는 출력 규칙이다. 각 스킬의 SKILL.md에서 이 파일을 참조한다.

## 파일명 규칙

```
{산출물유형}_{사업명}_{YYYYMMDD}.md
```

- `{산출물유형}`: 스킬별 고정값 (예: `서비스분류`, `비즈니스규칙`, `용어사전`)
- `{사업명}`: 입력에서 추출한 사업명. OS 금지 문자(`\ / : * ? " < > |`)와 공백은 `_`로 치환
- `{YYYYMMDD}`: 오늘 날짜

**revise(수정) 스킬의 경우**: 버전 번호를 파일명 뒤에 추가  
예) `비즈니스규칙_쇼핑몰프로젝트_20260523_v0.2.md`

## 출력 모드

**기본: 파일 생성 모드**
- 작업 디렉터리(현재 작업 경로)에 파일 저장
- 생성 완료 후 답변에 **절대 경로**와 한 줄 요약을 포함

**대화창 출력 모드** (아래 키워드가 입력에 포함된 경우):
- `"보여만 줘"`, `"파일 만들지 마"`, `"여기에 출력"`, `"대화창에"`, `"표시만"`
- 파일을 만들지 않고 마크다운 본문 전체를 대화창에 출력

## 버전 이력 표

모든 산출물 파일 하단에 반드시 포함:

```markdown
## 문서 버전 이력

| 버전 | 일자 | 작성자 | 변경 내용 |
|:---|:---|:---|:---|
| v0.1 | YYYY-MM-DD | 초안 작성 | 최초 생성 |
```

**revise 스킬**: 기존 버전 이력에 새 행 추가, 버전은 +0.1 올림.

## 추측 표시

확인이 필요한 내용은 인라인 주석으로 표시:
```
<!-- TODO: 확인 필요 -->
```

## 기존 파일 존재 시

동일 파일명이 이미 존재하면 덮어쓰기 전에 사용자에게 확인. revise 스킬은 버전 번호가 다른 새 파일을 만들므로 충돌 가능성 낮음.

## 언어 원칙

- 문서 전체 한국어로 작성
- 기술 고유명사(React, Spring Boot, JWT, REST API 등)는 원문 유지
- 영어 입력이 섞여 있어도 문서는 한국어로 통일

## GFM 표 형식

헤더 구분자에 정렬 명시:
- 좌측 정렬: `:---`
- 중앙 정렬: `:---:`
- 우측 정렬: `---:`
