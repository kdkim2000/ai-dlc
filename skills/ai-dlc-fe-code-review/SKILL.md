## 검증 항목

### TC — TypeScript 타입 안전성
| 코드 | 검사 항목 | 심각도 |
|:---|:---|:---:|
| TC-001 | `any` 타입 사용 (`as any`, `: any`) | 높음 |
| TC-002 | 타입 단언(`as XXX`) 남용 — non-null assertion(`!`) 포함 | 중간 |
| TC-003 | null/undefined 처리 누락 (옵셔널 체이닝 미사용) | 중간 |
| TC-004 | 함수 반환 타입 미명시 (추론 불가능한 경우) | 낮음 |
| TC-005 | Props 인터페이스 미정의 (`props: object` 또는 인라인 타입 누락) | 중간 |

### LC — 레이어·컴포넌트 설계
| 코드 | 검사 항목 | 심각도 |
|:---|:---|:---:|
| LC-001 | 페이지 컴포넌트 150줄 초과 (분리 필요) | 중간 |
| LC-002 | API 호출이 컴포넌트 내 useEffect에 직접 존재 (Custom Hook 미분리) | 높음 |
| LC-003 | Zustand store가 서버 상태(API 데이터) 관리 (React Query 미사용) | 중간 |
| LC-004 | 인라인 스타일 사용 (`style={{ ... }}`) — Tailwind 미사용 | 낮음 |
| LC-005 | 컴포넌트 파일명이 PascalCase가 아님 | 낮음 |

### PF — 성능 안티패턴
| 코드 | 검사 항목 | 심각도 |
|:---|:---|:---:|
| PF-001 | useEffect 의존성 배열 누락 또는 잘못된 의존성 (exhaustive-deps 위반) | 높음 |
| PF-002 | 렌더링마다 새 객체/배열/함수 생성 (useMemo/useCallback 미적용) — prop으로 전달하는 경우 | 중간 |
| PF-003 | 대용량 목록에 가상화 미적용 (React Query 페이지네이션 없음) | 중간 |
| PF-004 | 모든 API 호출 후 invalidateQueries 없이 상태 갱신 | 중간 |

### SC — 보안
| 코드 | 검사 항목 | 심각도 |
|:---|:---|:---:|
| SC-001 | `dangerouslySetInnerHTML` 사용 (XSS 위험) | 높음 |
| SC-002 | localStorage에 민감 데이터 평문 저장 (비밀번호, 주민번호 등) | 높음 |
| SC-003 | 인증 없이 접근 가능한 보호 라우트 (`PrivateRoute` 미적용) | 높음 |
| SC-004 | 환경 변수를 소스코드에 하드코딩 (`http://prod-api.example.com` 등) | 중간 |

### A11Y — 접근성
| 코드 | 검사 항목 | 심각도 |
|:---|:---|:---:|
| A11Y-001 | 이미지에 `alt` 속성 누락 | 중간 |
| A11Y-002 | 버튼에 텍스트 또는 `aria-label` 누락 (아이콘 전용 버튼) | 중간 |
| A11Y-003 | `<label>`과 입력 필드 연결 누락 (`htmlFor`/`id` 미일치) | 중간 |
