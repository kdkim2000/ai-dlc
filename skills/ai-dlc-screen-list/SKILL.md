# AI-DLC 메뉴 구조·화면 목록 도출

유즈케이스·FR 목록을 분석하여 메뉴 계층 구조와 화면 목록(SCR-NNN)을 도출하고, 역할별 접근 권한과 UC 연계를 포함한 **화면 목록 문서**를 생성한다.

공통 출력 정책: `${CLAUDE_SKILL_DIR}/../ai-dlc-common/references/output-policy.md` 참조.

## 트리거

- "메뉴 구조 만들어줘", "화면 목록 도출", "화면 목록 뽑아줘", "메뉴 설계해줘"
- "화면 리스트 작성", "사이트맵 만들어줘", "네비게이션 구조 설계"
- "화면 목록 작성", "SCR 목록 만들어줘"
- 유즈케이스 문서를 주며 "화면으로 나눠줘"라고 할 때

## 입력

- **필수**: 유즈케이스 문서 또는 FR 목록
- **선택**: 서비스 카탈로그(SC 목록), 역할·권한 정보, 설계 기초 추출 문서

## 분석 절차

1. **UC/FR에서 화면 단위 추출**: 동사 기준 분리
   - 조회/목록: `목록`, `조회`, `검색` → 목록 화면
   - 등록: `등록`, `신청`, `입력` → 등록 폼 화면
   - 수정: `수정`, `변경`, `편집` → 수정 폼 화면
   - 상세: `상세`, `조회` → 상세 화면
   - 승인/처리: `승인`, `반려`, `처리` → 처리 화면
2. **메뉴 계층 설계** (GNB > LNB > 화면 3단계 원칙)
   - SC(서비스 카탈로그)가 있으면 SC 단위를 GNB 기준으로 활용
   - SC 없으면 UC 도메인(액터·기능 군)으로 그룹핑
3. **SCR-NNN 채번** (001부터, 메뉴 계층 순서대로)
4. **UC 연계**: 각 SCR에 해당하는 UC-NNN 매핑
5. **역할별 접근 화면 매핑**: 액터별 접근 가능 SCR 목록
6. **텍스트 사이트맵 트리** 생성
7. **`template.md` 기반 화면 목록 문서 생성**

## 화면 유형 분류

| 유형 | 설명 | 예시 |
|:---|:---|:---|
| LIST | 목록/검색 화면 | 회원 목록, 주문 검색 |
| FORM | 등록/수정 입력 폼 | 회원 등록, 주문 수정 |
| DETAIL | 상세 조회 화면 | 회원 상세, 주문 상세 |
| PROC | 승인/처리 화면 | 주문 승인, 반려 처리 |
| DASH | 대시보드/통계 화면 | 관리자 대시보드 |
| AUTH | 인증 관련 화면 | 로그인, 비밀번호 변경 |

## 산출물 포맷

파일명: `화면목록_{사업명}_{YYYYMMDD}.md`

`${CLAUDE_SKILL_DIR}/template.md` 골격 사용:

1. **메뉴 구조 (계층 트리)**
2. **화면 목록** (SCR-NNN, 유형, UC 연계, 우선순위)
3. **역할별 접근 화면 매핑**
4. **화면-UC 커버리지**

## 엣지 케이스

- **단일 페이지 앱(SPA)**: 화면 대신 "뷰(View)" 단위로 표현, 동일 SCR 채번 방식 적용
- **모바일 앱**: 화면 유형에 `NATIVE_VIEW` 추가, 탭·드로어 메뉴 구조 반영
- **화면 수 100개 초과**: 메뉴 그룹별 화면 목록 분리, 전체 SCR 요약 표 포함
