# AI-DLC 사용자 매뉴얼

> 화면정의서·유즈케이스에서 화면별 사용법, 단계별 절차, 입력 필드 안내, 오류 메시지를 추출하여
> 최종 사용자가 매뉴얼만으로 시스템을 완전히 사용할 수 있는 `사용자매뉴얼_*.md`를 생성한다.

## 트리거

- "사용자 매뉴얼 만들어줘", "사용자 가이드 작성해줘"
- "사용 설명서 만들어줘", "시스템 사용법 문서화해줘"
- "운영 매뉴얼 작성해줘", "사용자 안내서 만들어줘"
- "어떻게 사용하는지 문서 만들어줘", "화면별 사용법 정리해줘"

## 입력

### 자동 탐색 (필수)
- `화면정의서_*.md` 또는 `화면목록_*.md`

### 자동 탐색 (선택, 있으면 보강)
- `유즈케이스_*.md` — 업무 시나리오 맥락
- `페르소나_*.md` — 사용자 그룹 구분
- `비즈니스규칙_*.md` — 유효성 규칙·제약 안내

## 처리 절차

1. **산출물 탐색 및 읽기**
   - 화면정의서/화면목록 Glob → Read (필수)
   - 유즈케이스, 페르소나, 비즈니스규칙 Glob → Read (있으면)

2. **사용자 그룹 파악**
   - 페르소나 또는 유즈케이스 액터에서 사용자 그룹 추출
   - 없으면 화면정의서의 "접근권한" 컬럼에서 추론

3. **화면별 섹션 생성** (SCR-NNN별 반복)
   각 화면에 대해:
   - **화면 목적**: UC 연계 설명 (1~2문장)
   - **화면 진입 방법**: 메뉴 경로 또는 URL
   - **화면 구성 요소**: ASCII 레이아웃 (가능하면 화면정의서에서 재사용)
   - **단계별 사용법**: 번호 매김 절차 (행동 → 결과)
   - **입력 필드 안내**: 필드명·형식·유효성 규칙 표
   - **주요 버튼 기능**: 버튼명 → 동작 설명
   - **오류 메시지 안내**: 오류 상황 → 메시지 → 조치 방법 표

4. **업무 흐름 다이어그램 생성** (유즈케이스에서 추출)
   - 주요 업무 시나리오별 화면 이동 순서 ASCII 다이어그램

5. **FAQ 섹션 생성** (비즈니스 규칙·유효성 제약에서 추출)

6. **template.md 기반 파일 생성**

## 산출물

파일명: `사용자매뉴얼_{사업명}_{YYYYMMDD}.md`
- 출력 시 절대 경로 + 포함된 화면 수 + 사용자 그룹 수

## 엣지 케이스

- **화면정의서만 있고 유즈케이스 없는 경우**: 화면 구성 요소 기반으로 사용법 작성, 업무 시나리오 섹션 생략
- **화면이 20개 이상**: 사용자 그룹별로 관련 화면만 섹션화, 전체 화면 목록은 부록
- **페르소나 없는 경우**: "일반 사용자"/"관리자"로 구분하여 작성
- **FORM 화면**: 입력 필드 유효성 규칙을 반드시 포함 (비즈니스규칙 문서 참조)
